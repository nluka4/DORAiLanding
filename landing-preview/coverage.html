Each column is counted once, by where its value normally starts for a single firm with a tagged cloud. These are columns, not effort: a notice period can take longer to find than twenty copied IDs. The scan can only fill services a person has already registered.

What it does by itself

The work that is factual, repetitive or checkable.

  • Reads your cloud

    Resources, regions, replicas, cost, backups and security alerts where Azure and AWS expose them, plus SaaS apps from Entra ID and Okta. Access is read-only.

  • Links resources to services

    Through resource IDs on a service, or matching contract, function and service-type values. It does not guess a link.

  • Fills facts and repeats

    It puts scanned facts in the register’s templates, copies what you typed once into every template that needs it, and works out totals and defaults.

  • Checks changes before deploy

    Five rules read a Terraform plan. A High finding fails the pipeline. No AI takes part.

  • Points out gaps and risks

    Empty required cells, broken references and conflicting rows are errors. Weak backups, concentration and unknown vendors are warnings for a person to assess.

  • Builds the files

    All 15 templates as an EBA xBRL-CSV package, and a PDF for people. While errors remain, the package can only be a marked draft.

What it never does

  • Create a provider, contract, service or function from a scan
  • Read your contracts
  • Find subcontractors
  • Decide that a function is critical or a risk is acceptable
  • Create or change cloud resources
  • Submit to your authority

The tradeoffs

Each shortcut saves work and costs something.

ChoiceYou getYou give upWhat to do
Rules make the findings, not AIThe same input gives the same answer, and you can read why.It sees only what five rules cover. An untagged resource can’t trigger the critical-function rule, and deleting one raises no finding.Review deletions and untagged resources yourself.
Tags link cloud to registerLinks are explicit, with no guessing.Tag-only linking also needs a known service type. In the demo it finds €21,200 of the €40,000 yearly cost on contract C1.Tag everything and list resource IDs for types outside the built-in table.
Cost is estimated from billsA figure without collecting invoices.It is not the past year’s expense. With steady spend, AWS’s 14-day window gives 23–46% of the true figure, and Azure about 92%. A failed cost call leaves a gap.Use invoiced amounts before filing.
Location follows resourcesCountries come from evidence, and an unknown region is never assumed to be in the EU.It misses remote support and administration, and “country of provision” is just the most common one.Compare with the contract and data processing agreement.
A typed value can override the scanA correction survives the next scan.An old typed storage location can hide a real move.Compare typed locations with the inventory after each scan.
Defaults assume one entityMuch less repeated typing.Groups get the wrong user entity until someone sets it. A forgotten end date looks like an open-ended contract.Review defaults, especially for groups.
AI drafts and a person decidesA faster first answer, with a reason and a source.A valid citation can still fail to support the value, and the model rates its own confidence.Read the passage before accepting. The decision is yours.
AI is optionalThe server runs with no key and no network.The default is a keyword-based stand-in. A real model receives names, tags and the facts behind each question.Choose the provider deliberately and check what may be sent to it.
Templates are built when you askThey follow the latest scan with no sync job.The same register can give different figures after the next scan.Archive every package you file.
The CI check works offlineIt needs no server or login in the pipeline.It trusts a copy of the register, which can go stale.Refresh that copy whenever the register changes.
Risk warnings don’t block exportAn incomplete view of backups or vendors can’t stop a filing.A package can be final with serious warnings open.Record a decision on every warning.
Your firm hosts itThe register and cloud credentials stay on your infrastructure.You run updates, off-site backups and availability. There is one server per install.Give the server an owner.

Check by hand before filing

Current gaps in version 1.1.1, found by testing or reading the code on 22 November 2026.

  1. “Ready” does not mean complete

    Readiness checks the rows that exist. With a scanned cloud and no providers, contracts or functions, the final package is still produced.

    Compare the register with your contract list and the inventory.

  2. Some invalid values reach the final package

    An LEI with a bad checksum and an end date before the start date are caught by basic validation, but that validation does not block the export.

    Clear basic validation as well as readiness.

  3. Two kinds of accepted suggestion stay out of the register

    Accepting a service type or a business function records the decision only. The four judgement columns and GLEIF values are written to their cells.

    Enter the type or function on the service, or fix the tag.

  4. Pending suggestions don’t raise a warning

    They wait on the review screen. An affected cell shows as missing if it is required.

    Empty the review queue before export.

  5. A blank parent becomes “its own parent”

    Readiness never asks for the ultimate parent. The export fills a blank with the provider’s own code.

    Confirm the parent of every provider.

  6. Provider totals can mix currencies

    In testing, a €40,000 and a $1,000 contract were totalled as €41,000.

    Enter every contract of a provider in one currency.

  7. Some cell edits have no effect

    A legal name or contract cost set on the template cell, including a legal name accepted from GLEIF, loses to the value on the provider or contract.

    Edit the provider or contract itself.
